## 총평 (냉정하게)

**엔지니어링 규율은 성실하지만, 시스템의 핵심이 거꾸로다.**
자체 백테스트가 기각한 전략(vb, 몬테카를로 손실확률 98.5~100%)을, 한 번도 백테스트된 적 없는
유니버스(당일 거래대금 상위 스카우트 종목)에, 백테스트 가정보다 체계적으로 불리한 체결(30초 폴링
+0.4% 마진 + 동시호가와 충돌하는 12초 취소)로 실행하고 있다. 안전장치(이중 잠금, 화이트리스트,
예산 분리)는 잘 쌓았지만 그것들이 딛고 선 상태(장부)는 실계좌와 대조된 적이 없고, 이미 불일치가
발생해 있다. **현 상태의 실전 운용은 전략이 아니라 마찰비용을 지불하는 무작위 매매에 가깝다.**

## Critical — 지금 돈이 걸려 있는 문제

**C1. 기각된 전략이 실전 가동 중** `[전략]`
vb는 자체 백테스트에서 3종목 전부 손실(비용 차감 전 gross조차 마이너스), MC 손실확률 98.5~100%.
손익분기 승률 43~58% 필요한데 실측 25~33%. 거래당 기대손실 -0.4~-0.8% → 예산 10만원 기준
60거래면 25~40% 통계적 확정 소진. **"3일차 손익 +692원"은 표본이 없다는 뜻이지 전략이 작동한다는 뜻이 아님.**

**C2. 검증과 운용의 완전한 분리** `[전략]`
백테스트한 3종목(삼전·하이닉스·KODEX)은 예산으로 1주도 못 사고, 실제 사는 종목(스카우트 픽)은
백테스트된 적이 없음. 즉 **지금 돌아가는 시스템 전체가 어떤 검증도 통과한 적 없음.**

**C3. 장부-실계좌 대사(reconciliation) 전무** `[정확성·체결·운영 공통 1위]`
체결확인 실패·취소-체결 race·병행 프로세스 덮어쓰기가 전부 "유령 포지션"으로 수렴하는데
이를 잡을 대조 로직이 없음. 파일 저장은 비원자적·무잠금이며, 손상 시 **조용히 빈 장부로 초기화
(킬 스위치 해제 포함)**. 테스트가 실전 로그를 오염시킨 것도 같은 뿌리.

**C4. KR 종가청산 ↔ 동시호가 구조 충돌** `[체결]`
15:20~15:30 단일가 구간에는 체결이 15:30에만 일어나는데, broker는 12초 대기 후 자가 취소.
청산 성공이 "15:30 순간에 우연히 주문이 살아있었나"의 동전던지기. 실패해도 done 마킹돼 재시도 없음
→ 비의도 오버나이트 → 다음날 갭하락은 -3% 스탑이 못 막음. (V·003350이 실증)

**C5. 손절이 봇 프로세스 메모리에만 존재** `[리스크·운영]`
거래소측 조건부주문(SINGLE/OCO — 토스 API 지원) 미사용. 맥북 잠들거나 와이파이 끊기면
모든 포지션이 무방비. 재시작 자동화(launchd KeepAlive)도 없어 크래시 = 수동 복구.
게다가 API 장애는 "CLOSED(휴장)"로 위장되고 하트비트는 계속 💓정상을 보냄.

**C6. 뉴스 모니터 = LLM이 직접 돈을 움직이는 유일한 무방비 경로** `[LLM]`
검증 없는 RSS 헤드라인 → LLM 판정 → 곧바로 시장가 강제청산. 오보·낚시제목·인젝션에 대한
방어 없음 (매수 거부권과 달리 청산은 실행이므로 파급이 큼).

  손절 쿨다운도 자정에 만료. 11월 서머타임 종료 후 악화. `[리스크×3관점 공통]`

- **H4. 돌파 감지→발주 38~69초 지연**: 매 틱 전 종목 400봉 재수집 + 발주 직전 동기 LLM 호출이

- **H8. 텔레그램 명령 처리 무보호**: /flat·/status 중 API 예외가 tick()을 뚫고 봇 전체를 죽임 —

- **H9. 토큰 401 / IP 403 자기복구 없음**: 최대 24시간 블라인드 가능. `[운영]`
