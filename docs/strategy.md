## 대원칙: 검증 게이트

어떤 전략이든 실돈을 만지려면 세 가지를 통과해야 한다:

1. **모의고사(OOS) 거래 30건 이상** — 표본 부족이면 판정 불가
2. **모의고사 평균 수익 > 0** — 학습 구간이 아니라 처음 보는 구간에서
3. **몬테카를로(3,000회) 손실확률 < 30%** — 거래 순서를 섞어 "운"을 검증

학습(IS)/시험(OOS) 구간을 나누는 건 커닝 방지, 몬테카를로는 "평균 뒤에 숨은 운의 크기"를
잰다. 체결 가정은 항상 보수적으로 (수수료+거래세+슬리피지+호가단위+갭 반영).

```bash
python3 run_backtest.py -t st            # 백테스트
python3 run_backtest.py -t st --mc       # + 몬테카를로
python3 run_backtest.py -t st --validate # 검증 게이트 기록 (실전 기동 조건)
```

## 가동 중인 전략

### st — Supertrend 추세추종 (기본)

- 주가의 큰 흐름이 하락→상승으로 **전환 확정된 날**(일봉 종가 기준) 다음날 시가에 사서,
  흐름이 꺾일 때(종가가 추세밴드 아래로) 판다. 익절 목표가 없다 — 추세를 끝까지 탄다
- **월 수 회 거래가 정상.** "오늘 왜 아무것도 안 사?"는 대부분 정상 동작이다
- 검증: OOS 50건 +7.35%/건, 몬테카를로 손실확률 0.7% ✅
- 왜 종가 기준인가: 장중에는 캔들이 미완성이라 가짜 전환이 섞인다. 종가(동시호가)가
  하루 중 가장 신뢰할 수 있는 가격

### 전환 스캐너 (2026-08-31 승격)

매일 15:20(동시호가)부터 **거래대금 상위 100 전체**를 스캔해 "오늘 전환"한 종목을 잡고,
하루 최대 2건을 다음날 시가 매수 예약한다.

- 검증: 4년 백테스트 OOS 231건 **+3.00%/건**, 포지션당 예산 1/2 분할 가정 몬테카를로
  손실확률 13.6% ✅
- **1건당 시장 예산의 50% 이내 분할이 승격의 전제조건** — 전액 몰빵이면 손실확률 31%로
  기각 조건이다. `config.SCANNER`의 `position_frac` 제거 금지
- 뉴스 거부권·리스크 한도·손절 등록은 일반 매수와 동일 적용. 기록: `logs/scanner_shadow.csv`

## 뉴스·AI의 역할 (매수 트리거 아님)

- **스카우트**: 뉴스를 읽고 어떤 종목을 지켜볼지 고른다 (후보군은 규칙이 생성)
- **뉴스 거부권**: 매수 직전 악재면 차단
- **뉴스 모니터**: 보유 종목에 치명 악재(거래정지/상폐/분식/횡령 헤드라인 3건+)면 자동 청산,
  일반 악재는 경보만 (판단은 사람)
- **전자공시(DART)**: 기사보다 빠른 원천 — 알림 + 재평가 트리거
- AI가 "사라"고 할 수는 없다 — AI 판단은 재현·검증이 불가능해 게이트를 통과할 수 없다

## 기각된 전략들 (같은 아이디어 재탕 금지)

전부 실데이터·생존편향 없는 유니버스로 검증했고, 데이터가 기각했다:

| 전략 | 모의고사 성적 | 왜 지는가 |
|---|---|---|
| 변동성돌파 (당일 급등 추격) | -0.96%/건, 손실확률 100% | 급등 추격 = 꼭지 매수 |
| 뉴스모멘텀 (분봉 급등 올라타기) | -0.66%/건, 승률 33% | 〃 — 5분 +2% 시점은 단기 꼭지 |
| 공시 눌림목 (공급계약 후 -2% 눌림 매수) | -1.62%/건, 승률 8% | 팝 후 눌림은 눌림목이 아니라 되돌림의 시작 |
| 스캐너(당일 거래대금 상위 유니버스) | -4.5%/건 | 당일 상위 = 어제 폭등 테마주 필터 |
| 인버스 ETF에 st (숏 대용) | 진입 0건 / IS -2.6%/건 | 인버스는 구조적으로 녹는 자산 |

상세 데이터·재현 코드는 `research/` 디렉터리에 있다.

## 새 전략 아이디어를 낼 때

아이디어가 시험대에 오르려면 네 가지를 갖춰야 한다:

1. **숫자로 적을 수 있어야** 한다 ("느낌 좋으면 산다"는 시험 불가)
2. **들어가기·나가기·손절** 셋 다 명시
3. **과거 데이터로 재현 가능**해야 한다
4. 위의 **게이트 3조건**을 통과해야 실전 투입

전략 코드는 `strategy/base.py`의 on_open/on_close 인터페이스를 구현하면 백테스트와
실전이 **같은 코드**를 호출한다 (미래참조 방지 구조).
