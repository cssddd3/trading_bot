## 텔레그램 (제어는 여기서만)

| 명령 | 동작 |
|---|---|
| `/status` | 보유(수익률순 정렬, 진입일·진입 사유 포함)·예약·예산·예수금·감시종목·AI 시황 메모·기능 상태 |
| `/stop` | 신규 매수 정지 (보유분 관리는 계속) |
| `/resume` | 재개 |
| `/flat` | 전량 청산 (킬 스위치) |
| `/restart` | 봇 재시작 (새 코드 반영) — 터미널 없이 원터치 |
| `/budget KR 100000` | KR 예산 변경 (영구 저장, US도 동일) |
| `/watch 005930` | 종목 수동 감시 추가 |
| `/unwatch 005930` | 수동 감시 해제 |
| (자유 질문) | "/" 없는 메시지는 AI 비서가 답변 (읽기 전용). 대화가 이어진다 — "아까 그 종목 왜 샀어?" 같은 후속 질문 가능 |

자동 알림: 매수/매도 체결, 매수 차단 사유, 악재 경보, 새 공시(📢), AI 추천 종목(🔭 뉴스·시황
기반 — 감시 추가만, 매수는 검증된 가격 규칙만), 전환 스캐너(🔍), 급락 브리핑(📉),
1시간 하트비트(안 오면 봇 사망 → 컴퓨터 확인), 마감 리포트, 크래시.

마감 리포트에는 **AI 추천 1주 성적표**가 포함된다 — 최근 7일간 AI가 추천한 종목이
추천 시점 대비 얼마나 올랐/내렸는지 매일 자동 채점 (추천의 신뢰도를 눈으로 확인).

마감 후에는 **🧠 저녁 리뷰**가 온다 — AI가 오늘의 매매(또는 무매매)를 평가하고, 보유
종목의 진입 논지가 유효한지 점검하고, 백테스트할 가치가 있는 가설을 남긴다. 이 리뷰는
운용 일지(공유 기억)에 쌓여 다음날 아침 스카우트가 이어받는다 — AI 역할들(스카우트·
뉴스 거부권·비서·리뷰)이 같은 기억을 공유하는 한 사람처럼 동작한다. 단, 가설은
백테스트 검증을 통과해야만 실전에 반영된다 (AI는 여전히 매수 방아쇠를 못 당긴다).

## 웹 대시보드 (읽기 전용)

봇이 켜져 있으면 함께 뜬다 — 보유·평가손익·예약·감시종목·최근 체결을 10초마다 갱신.
제어 기능은 일부러 없다 (같은 와이파이 누구나 열 수 있으므로, 제어는 chat_id로 잠긴 텔레그램만).

- 봇 컴퓨터에서: http://localhost:8787
- 같은 와이파이 폰에서: `http://<컴퓨터IP>:8787` (맥 IP: 시스템 설정 > Wi-Fi > 상세정보)
- 포트 변경: `config.py`의 `DASHBOARD`

## 예산과 예수금

- **예산** = 봇이 써도 되는 상한 (`/budget`으로 설정, 실현손익만큼 복리로 변동)
- **예수금** = 계좌의 실제 현금 (매도 대금은 D+2 입금)
- 실제 매수 가능액 = **min(예수금, 예산 잔여)** — 예산만 올리고 입금을 안 하면 매수가 불발된다

## 직접 산 종목을 봇에 맡기기

```bash
python3 run_dryrun.py --adopt 005930,000660 --live
```

명시한 종목만 편입되고 (손절/뉴스감시/청산을 봇이 관리), 나머지 기존 보유분은 절대 건드리지 않는다.

## 지인과 공유하기 (텔레그램 채널)

텔레그램에서 새 채널 생성 → 봇을 관리자로 추가 → `.env`에
`TELEGRAM_BROADCAST_CHAT_ID=@채널이름` 추가 → 재시작.
이후 스카우트 픽(근거 포함)·매수/매도(종목·가격·수익률)·새 공시·스캐너 신호가 채널로도
나간다. 지인은 채널만 구독하면 된다. 계좌 수치(예수금·예산·수량)는 채널에 나가지 않고,
봇 제어는 여전히 주인 개인 챗만 가능.

> ⚠️ 소수 지인과의 무료 공유 용도. 불특정 다수 대상 유료 리딩은 유사투자자문업 규제
> 대상이 될 수 있으니 범위를 넓히기 전에 전문가와 상의할 것.
